## §2 诊断（三个候选，按可检验性排序；不再靠布局变量）

### H1 · 拼接不自洽（本文的主假设）
每个块的 KV 是**在完全孤立的情况下编码**的（一次 encode 只有这一块）。
拼接进同一条序列后，块与块之间的注意力建立在"彼此从未见过对方"的 KV 上。
块的 K/V 不含任何关于其它块的信息，而问题是问在它们之上的——**这是一次语义不一致的近似**。

· 能解释：为什么单块/三块好、四块坏（块越多越不自洽）；
· 能解释：为什么同位置同大小、只换张量字节就翻转（一致性是内容级的，不是几何级的）；
· 能解释：为什么问哪块哪块常能用（该块的 KV 自洽程度最高）。

### H2 · 注意力预算稀释
四块 70 cells，问题从 4096 处对全部 cell 做 softmax；块越多，分到目标块的权重越少。
但 `iso_dup4`（70 cells，pass）与 `iso_fac_pp18`（70 cells，fail）**cell 数完全相同**，纯稀释说不成立——
除非稀释阈值恰好落在内容相似度上。**降为次要。**

### H3 · 位置/旋转误差
块被 `repos_local` 重旋转到目标位置（H→rope→H）。位置越远、跨度越大，误差累积。
但 `iso_dup4` 与 `iso_fac_pp18` 位置逐段相同 ⇒ 同样不支持它单独成立。**降为次要。**

⇒ **主攻 H1。** 而 H1 的一个直接推论是：**我们必须让"块之间互相可见"成为可能，或者让"问题只看一块"。**


### §2.1 四臂实验（T-028c）带来的两条修改（2026-10-24 夜）

**(a) 顺序假设：用这种构型测不了（不是"未测出"）**
```
  H 臂 preamble 原文："我住在哪？我住在广陵路 12 号 2 单元 602，一直没搬家。。。。"
  H 臂结果：ok=True，答案"我住在广陵路12号2单元602。"
```
⇒ 答案就在上下文文本里 ⇒ H 通过只证明"文本被读到"。
⇒ **任何"关于记忆 X 的前序问答"都必然包含 X 的内容** ⇒ "先问过 X" 与 "X 的内容出现在上下文"
  **逻辑上不可分离** ⇒ 顺序共线**无法用问答型 preamble 检验**。此项终结，不再尝试。

**(b) 最锋利的一条事实：远文本可用，近块不可用**
```
  [3853,3885) 的 32 token（在最低块 car [3885,3904) 之下）—— 模型确实用上了：
    四臂 sha 两两不同，且都与 70-cell 基线 e63faeff 不同；
    含家事实的那臂 → home 通过；格式指令臂 → 答案长度 43 vs 36、形态变化。
  ⇒ 提问点 4096 的注意力横跨四个记忆块，一直够到 3853 ⇒ **"够不到"被排除；H3 进一步降级**。
  ⇒ 而最近的块 home [4075,4096] 无 preamble 时 18/18 失败。
```
**一句话：远的东西读得到，近的块用不上 ⇒ 问题不在距离，在那块 KV 本身没被采纳。**
这加强 H1（拼接不自洽），并把下一步定死为"消融 / 路由"。

**(c) 由此新增的两个决定性测量（T-030 第 3 步）**
```
  测量 A（阶段 B 的 go/no-go）：iso_car_back 上**只保留 home 参与注意力**，问 home。
      home 通过 ⇒ 路由即解，直接做阶段 B；
      home 仍失败 ⇒ 放弃路由，转阶段 C（整体编码）。
  测量 B（谁在压制）：分别只消融 home / car / project / habit，
      看"拿掉哪块之后 home 变好" ⇒ 那就是压制者。
```
  **测量 A 只需一次跑，却能把方案分成"能修"和"要换做法"两条路。它优先于阶段 A 的完整表。**

## §3 方案（三阶段，A 先行，A 的产物同时是 B 的输入）

### 阶段 A · 装仪表：**块消融**（测"每块对答案的贡献"）

**为什么用消融而不是注意力权重**：llama.cpp 的 flash-attn 路径不返回注意力权重，
要拿到权重要关掉 FA 并改图，成本高、还会改变数值路径。
而**消融只需要用引擎已有的 KQ mask**：把某一块的 cell 置为 `-INFINITY`，看答案/概率怎么变。
这对我们的问题（"这块有没有参与生成"）更直接，也更便宜。

**现成的钩子**：`llama.cpp/src/llama-kv-cache.cpp:1873 set_input_kq_mask_impl()`，
其中 `mask_keep = 0.0f` / `mask_drop = -INFINITY`（1887–1888），`data[idst + j] = mask_drop`（2017）。
**这里就是唯一需要改的地方。**

**改什么**：在该函数内新增一个默认关闭的开关
```
  LLAMA_KV_ABLATE=<lo>:<hi>      # 位置区间，闭开 [lo,hi)；把落在其中的 cell 的 mask 置为 mask_drop
```
· 未设置时**一行行为都不变**（必须逐字节可验）；
· 设置时只影响 mask 取值，不动 KV、不动位置、不动控制流；
· 另加 `[ABLDBG]` 一行统计：被 drop 的 cell 数与区间。

**度量什么**（驱动侧，不需要 cpp 再做别的）：
对同一个问题，跑 N+1 次前向：基线 + 每次消融一块；记录**首个答案 token 的 logprob**与 top-5 分布，
算每个块的**影响量** = 基线 logprob − 消融后 logprob（正数 = 这块在帮忙）。

**这一步要回答的问题（一条就够）**：
```
  单块布局里，消融该块 → 影响量应大（证明仪表有效，正向对照）
  四块布局里，消融 home → 影响量是多少？若接近 0 ⇒ home 的 KV 根本没参与生成（H1/H3 方向）
                                    若很大而答案仍错 ⇒ 参与了但被别的块压过（H2 方向）
```
**这是今晚第一次能给出"因果贡献"而不仅仅是"答案对错"。**

**验收**：
1. 不带 env 时：日志 0 增量、答案 sha 与历史一致（`7ec1430d…22fd`）；
2. 带 env 消融一块时：被 drop 的 cell 数 == 该块 cells；
3. 正向对照：`iso_home_only` 上消融 home ⇒ 影响量显著 > 0；
4. 给出 `iso_dup4` 与 `iso_fac_pp18` 两布局 × 四块的影响量表。

### 阶段 B · 改路由：让问题只看它该看的那块（工程修复）
**依据**：单块能答对（事实 2），多块才坏。既然如此，**把多块在生成时降级为"单块"**。

**改什么**：
1. 复用阶段 A 的统计，在**问题 token 解码完成后、生成开始前**，对每个块算一个相关性分数；
2. 取 top-1（或 top-k，k 可配）；**对未选中的块设置注意力遮罩**（复用现有 mask 通路）；
3. 生成阶段只用被选中的块。

**新增对外接口**（shim 层）：`kvshim_route(seq, mode)`，mode ∈ {`off`, `top1`, `topk:<k>`}；默认 `off`，**不改变既有行为**。

**验收矩阵**：四个四块布局 × 各自的四个目标，共 16 格；要求**至少 14/16 通过**，且 `iso_car_back` 上 home 必须通过。
若 top-1 路由后 home 仍失败 ⇒ 说明不是"选错块"，而是"选对了也读不出"，转阶段 C。

### 阶段 C · 改做法：整体编码（根治，成本最高）
**改什么**：不再"孤立编码 + 拼接"，而是**把对话与全部记忆块放在一起做一次 encode**，得到一份自洽的 KV。
代价：每次新增记忆都要重编码全部上下文（可用增量：只对新增段编码 + 保留旧段，但那是另一个工程问题）。
**触发条件**：阶段 B 未达 14/16。
