# M2 红/绿套件 · 七条断言（S1·S2·S3a·S3b·S4·S5·S6）先红后绿

## 0. 定性核心

> 本方案不是摆放偏好，而是**给一个有损操作定最少调用次数**：每块只做一次 repos_local(delta=target-base)、先远后近放置。
> 依据（两次独立观测，同向）：
> - 观测 A：单次重转 => bytes_changed/total = 1,070,339/2,194,932 = 0.4876（slot2 0.4849 / slot3 0.4837），字段 own_repos_rewrite.ratio；
> - 观测 B：同一目标位上 +3/-3 往返重转 => pos_max 4095/4031/3967 逐位不变，三块 post 与 roundtrip 哈希全变、长度不变（见第 5 节）。
> => 两次不同做法同向 => 每一次挂载都是一次有损往返，不是测量假象。
> => 「先远后近、一次到位」= 把重转次数压到每块一次。

## 8. 三处按 lead 裁定改的（第二轮）

### 8.1 S1m 降级为**回归锁**（我上一轮把它夸高了）
`gaps[1] = 4075-4031-1 = 43`、`gaps[2] = 4014-3967-1 = 46` —— **就是从冻结几何反推的缝宽**，目标位置也是抄的常量。
**把答案拆成「块 + 缝」再喂回去，当然逐位复现。** 所以：
- S1m 证明的是「**给定同一组空隙能复现同一布局**」= **几何不漂的回归锁**；
- **不是**「规划器会自己布局」，更不是「它能推出这组缝隙」。

### 8.2 `pool_bytes` 档**删除**：它恒真
算术：`855,638,016 / 104,448 = 8,192 = n_ctx` —— **恰好相等**，即 `pool_bytes = n_ctx * bytes_per_token`。
⇒ `cell_ok => bytes_ok` 必然成立 ⇒ **bytes 档恒真**。唯一让它假的是 P8 用的 `1,000,000/104,448 = 9.57 token` 的池，**连一个 cell 都放不下，没有物理意义**。
**更根本的事实（必须写下来）**：**池就是整个 KV cache**，所以「上下文够」与「池够」是**同一个约束的两种货币写法，不是两个约束**。**预算只有一个。**
`planner.py` 里 pool 的 `raise` 保留作防御性断言，但**不进判据表**。
### 8.2b P8 为何删除
**它的「可分离」是用 9.57 token 的荒谬预算换来的** —— 用一个没有物理意义的输入去证明判据独立，这不是判别力，是构造出来的假独立。

### 8.3 S6：两档都算拒绝义务 + **校 `refused.reason`**
`S6_nctx` 与 `S6_pool` 两条断言分别要求 `reason == 'n_ctx'` / `'pool_bytes'`；**「拒了但理由错」判红**。
S2 与 S6 的关系也写死：**在「无淘汰」前提下，预算越界必然伴随拒绝义务 ⇒ S2 的红必然伴随 S6 的红；这是结构耦合，不是判别力不足。**

### 8.4 `base` 的不变式需要**外部锚**（检测员的说法比 lead 原话更准）
- 不变式 `base + cells - 1 == pos_hi` 若两字段互为派生则**必然为真** ⇒ 单独用它是恒真候选；
- 所以配**外部锚**：`home 4075/4095`、`project 4014/4031`、`habit 3956/3967` —— **来自冻结几何，不是本模块推导**（`CORE_base_anchor`）；
- 并在 **`new_cells != 既有 cells`**（插入场景，19 vs 21/18/12）**重验一次**（`CORE_base_poshi_newcells`）。
- **记一句**：这不是「一个词指两样东西」，而是**「一样东西没有名字」** —— `base` 在系统里无名，每处临时算，**所以没人能对它下断言**。

### 10.1 这次测出来的两个陷阱（都是我们自己的，不是引擎的）
1. **「插入后返回 -1」是我错，不是插入坏**：我把第二问写在**对话起点**（4096），那是**覆写已有对话**的位置 ⇒ engine 返回 -1。
   定位实验 `insert_localize.py` 的 **D0（不插入、只连问两次）同样 -1** ⇒ 与插入无关。**正确做法：写在 `raw_pos_max+1`（对话末尾）。**
   **纪律**：失败读数先找对照，否则会把「我用错 API」记成「功能不成立」。
2. **`eng.pos_max(LIVE)` 对 share 进来的 cell 返回 -1**（共享不算 seq 自己的 pos），必须用 `P.raw_pos_max(eng, LIVE)`。
   我先用 `pos_max` 算对话末尾 ⇒ 得到 0 ⇒ `repos_local(chat,+12)` **moved 0**（区间为空），一步没动却全报 ok。**「全 ok 但什么也没做」比报错更危险。**

### 10.2 顺手得到的实测速率（与 §2.3 的推算对比）
`repos_local` 移动对话：**123.3 ms / 45 cell = 2.74 ms/cell**。
按此线性外推 5000 token ≈ **13.7 s**；而 §2.3 的推算是 **4.2 s**（`5000/50×42ms`）。
⇒ **推算偏低约 3 倍**。外推仍是外推（cell 数增大后未必线性、也含 cell_scan 成本），**所以不设门，只记**：`insert_elapsed_ms` 已落字段。
## 11. 判据分两层（lead 裁定）+ 一条场景纪律（本次最重要）

### 11.1 结构结论（进纪律区）
> **一条在部署规模上不可能触发的判据，不是判据，是带测试骨架的注释。** 它的「绿」与恒真不可区分；它的「红」只在人造参数下出现 ⇒ **红得再漂亮也不增加任何真实保证。**

它紧挨原有那条：
- 原条是**对数据**的要求：能红 + 能绿 + 两类取值都出现过；
- 新条是**对场景**的要求：**触发条件必须在真实工况里能发生。**

### 11.2 分两层
| 层 | 判据 | 计入 M2 验收？ |
|---|---|---|
| **域内** | `S1 几何` / `S3a 锚点` / `S4 不拖块` / `S5 字节` | **是** |
| **契约测试** | `S2 n_ctx 档` / `S3b tie-break` / `S6 拒绝` | 否（作为回归锁保留） |

**验收口径（写死）**：**M2 通过 = 域内四条全绿 + 真机插入一次成功。**
降级理由：**这三条测的是大负载行为，M2 的运行点是小负载** —— 算进验收是拿域外的红绿冒充域内的保证；删掉则让「将来规模上来会怎样」永久无判据。**降级是唯一诚实的处置。**

### 11.3 三处按裁定改的具体动作
| 判据 | 动作 |
|---|---|

### 13.3 `fact_ok` 的定义原文（贴给你，免得再有歧义）
```python
def fact_ok(fact, ans):
    if not fact:
        return False
    return norm(fact) in norm(ans)
```
- **检查什么**：期望事实串（如 `3月14`）是否作为**子串**出现在答案里；`norm()` 只去掉空白与中文标点。
- **不看什么**：**不看长度、不看是否编造、不看是否答非所问、不做排除性检查**。
⇒ 所以措辞改死：**「事实关键词命中（`fact_ok`），非答案质量」**；**`答案仍正确` 四字不再用于描述 `fact_ok`**。

## 16. 新问题：`answer` 字段到底是什么（**未验**，并写清为什么查不了）

一个以 `` 开头的答案串**不是一次完整生成**（完整应形如 `…思考……答案`）。要判它属于哪种情况：

**查不了，原因是仪器没有这个能力**：`ask_native` 只有一行调用 ——

### 22.3 本文件**不**登记自身 sha16（原节已删）

原先这里写着「本文件 = 某 bytes / 某 sha16」。**删掉的理由不是过期，而是结构性恒假**：
> **写这一节这个动作本身就改变了文件** ⇒ 它在写完的那一瞬间就已经错，**且永远不可能自洽**；没有任何更新频率能救。

这与「两次→三次」不同：那个**会**过期，这个**必然**过期。

**规则**：**一个文件不能包含关于自身内容的事实断言。** 要记「我是哪一版」，只能由**外部**记录（如 `MANIFEST.json`，最后生成，且不登记自己），或由**生成该文件的程序**写进日志（如 `provenance{planner_sha16, probe_sha16, run_utc}`）。
**判法**：看到「本文件 = 某 sha」，先问「写这句话的时候，这个 sha 还成立吗？」——**答案永远是不。**

**配套（写范围词时，范围词本身就是一个断言）**：
· 写「全文」⇒ 断言扫过全文；· 写「全部」⇒ 断言枚举完整；· 写「第 N 次」⇒ 断言语料里只有 N 次。
**三个词都在替你做你未必做过的普查。拿不准就写更小的那个范围 —— 写小了只是不全，写大了就是假。**

**配套（核对的对象）**：**核对的成本永远低于返工，但核对必须用在「确认对象」上，不能用在「确认结论」上。对象错了，结论再对也没用。**
