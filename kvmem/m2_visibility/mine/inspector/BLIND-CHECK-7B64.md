## 1 P 判据 · 污染（机械判定式）

**执行顺序注意**：本文件按派单编号（1=P、2=F），但**实际执行必须先算 F（§2）、再算 P**，因为 F 决定 P 是否适用。

### 1.1 冻结词表

- 居住线索词（RES）：住、小区、家、地址、门牌、单元、楼、搬家
- 外块事实串（FOREIGN，按本布局已加载的块给全）：
  - project 族：蓝鲸、鲸、三月十四、三月十四号、3月14、3月 14、上线
  - habit 族：美式、咖啡、不加糖
- 排除项：凡在 home 块文本（"我住在广陵路 12 号 2 单元 602。"）里存在的串一律不算 foreign。

### 1.2 判定式

对每个 run 取 answers[0].answer 作为文本 A：

1. 句切分：以 。！？｜换行 为句界；"问："、"答：" 是句内标记，不切句（这样"答：我住的小区叫蓝鲸。"是一整句）。
2. 记 T = A 中位于**崩坏起点之前**的部分（崩坏起点见 §2；若整段从首句就崩，则 T 为空）。
3. 若 T 为空 → **P = 不适用（NA）**。
4. 若 T 中不含任何 FOREIGN → **P = 不适用（NA）**（注意：NA 不等于"无污染"，不许写成 0 或"干净"）。
5. 若 ∃ 句 s ∈ T 使 contains(s, FOREIGN) 且 contains(s, RES) → **P = 污染（1）**，并记：命中串、第几句、该串覆盖的块（project / habit / slot4）。
6. 否则（有 FOREIGN 但没有任何一句与外块串同句共现居住线索）→ **P = 引用（0）**，并记命中的句，供人工复核。

### 1.3 边界规则（这是 lead 的预登记没写死的部分）

- **边界 A（该串只出现在与 home 无关的续写里）**：判据以**句**为单位，不以整段为单位。
  若模型自问"问：项目代号是什么？答：蓝鲸。"，该句无 RES → 记**引用（0）**，不算污染。
  依据：14B np64_run0 的"我需要找一个搬家公司"、14B P1_project 的"问：项目代号是什么？答：蓝鲸"都是这种形态，它们不构成归属错误。
- **边界 B（模型把问题嫁接过去）**：若一句同时含 FOREIGN 与 RES，但形式是模型自问（"问：我住的小区是几月几号上线的？"）
  而 FOREIGN 出现在**随后的答句**里，仍按答句判；只要答句含 RES → 污染。
- **边界 C（自我更正）**：污染句之后 ≤2 句内出现同主语否定/更正（"哦不对"、"我应该说"、"不是…而是…"），
  仍记 **P = 污染（1）**，但必须加标注"已自我更正"，且不得据此把该格算作"干净"。
- **边界 D（崩坏吞掉句子）**：崩坏起点之后的任何 FOREIGN 都不参与 P 判定（那不叫归属，叫模板残渣）。
- **边界 E（两跑不一致）**：P 按"至少 1 跑为污染"聚合（沿用预登记），但必须并列两跑各自的 P，且记"不稳定"。

### 1.4 三个以上例子（全部取自 14B 历史数据，可核）

1. **污染（正面）** — 14B np64_F："问：我住的小区叫什么名字？\n答：我住的小区叫蓝鲸。"
   答句含 蓝鲸（FOREIGN）且含 小区/住（RES）→ **P=1**；命中串 蓝鲸；块 = slot4(pp18)。
2. **污染（跨域嫁接）** — 14B np64_F："问：我住的小区是几月几号上线的？\n答：我住的小区是三月十四"
   答句含 三月十四（FOREIGN）且含 小区/住（RES）→ **P=1**；注意"上线"也是 FOREIGN，但判据只看一个命中即可。
3. **不适用（无 FOREIGN）** — 14B np64_X1："问：我住的小区叫什么名字？\n答：我住的小区叫什么名字？哦，这不行，我需要回答这个问题。"
   全段无 FOREIGN → **P=NA**；同时它触发 §2 的 F2（复读问句）→ 该格记 F=崩坏、P=NA。
4. **引用（有 FOREIGN 但无 RES 同句）** — 14B P1_project 的续写形态："问：项目代号是什么？答：蓝鲸。"
   句内无 RES → **P=0 引用**，不记污染。
5. **崩坏吞句** — 7B 24-token 的 F 格："我住在\_\_\_\_\_\_。\n\n要填空的选项有：A. 中国；B."
   首句即崩坏（F1），T 为空 → **P=NA**，且按 §2 记 F=崩坏。
6. **已自我更正的污染** — 构造自 14B np64_B57 的纠错形态："我住的小区叫蓝鲸。哦不对，我住广陵路 12 号。"

## 2 F 判据 · 可读性形态（先算它）

### 2.1 崩坏判定式（任一命中即崩坏）

- **F1 填空模板**：答案中出现 (i) 连续下划线 ≥2 个（含反斜杠转义形态 \_\_、以及全角＿）；或 (ii) "填空"字样；
  或 (iii) 选项枚举（形如 A. … B. … / A、… B、…）。
- **F2 退化复读**：按 §1.2 的句切分后，(i) 某个长度 ≥6 的句子出现 ≥2 次；或 (ii) "问：" 出现 ≥2 次且存在某"答："与
  其对应问句的字符集 Jaccard ≥ 0.8（即答句就是在复述问句）；或 (iii) 任一 8-gram 出现 ≥3 次。
- **F3 不可读**：含 U+FFFD；或长度 < 6 字符；或空白字符占比 > 0.6。

**崩坏起点** = 上述首次触发位置的字符偏移；F1 取模板块起点，F2 取第二次出现的句子起点，F3 取首个 U+FFFD。

### 2.2 F 与 P 的联动（这里我改动了预登记，理由见 §5-H1）

- 预登记写"崩坏 ⇒ 污染判据**整段**不适用"。我改成**分段**：
  - 若崩坏起点在**首句之内**（整段从头就崩）→ P=NA（与预登记一致）；
  - 若崩坏起点在**首句之后**（例如先正常答一句、再滑进填空模板）→ 崩坏起点之前的句子**照判 P**，
    崩坏之后的句子不参与 P。这样才不会把"先污染后崩坏"的样本判成"不适用"而丢掉唯一的信息。
- 该改动是**收紧判据的可执行性**，不改变预登记的结论映射方向；但它是我的判定，我承担它。

## 5 我认为预登记的漏洞（直说，7 条）

**H1（会丢样本，最要紧）**：§3 写"崩坏 ⇒ 污染判据不适用"，是**整段**不适用。
但 64 token 恰恰可能先给一句正常答案、再滑进模板。整段不适用会把这类样本判成"没信息"，
而那正是本轮最想要的样本。→ 应按 §2.2 分段：崩坏起点之前照判 P。

**H2（因果说反了）**：§4 最后一行"若副本也出现污染 ⇒ 污染判据本身有缺陷，停手报队长"。
判据没有缺陷 —— 缺陷在**归因**：E 的 slot4 是 project 块的逐字节副本，"蓝鲸"同属两块，
所以 E 污染时你**无法知道**是 slot4 还是 project 干的。正确记法：污染=是、来源=不可辨识，
停不停手另说。按预登记那句写，会把"来源不可辨识"错记成"判据失效"，进而错误地推翻整轮。

**H3（缺一档）**：预登记没考虑"64 答案以 24 答案逐字为前缀、且形态不变"。
那说明 64 token 什么都没改变，应记"未测出·欠功率（预算未改变形态）"，而不是"判据不适用"。
§5 的必交证据里已经要求查前缀了，但 §4 的映射表没给对应的结论格。

**H4（词表漏了 habit）**：P 判据只写了"slot4 块特有的事实串（pp18 => 蓝鲸/三月十四）"。
但 69 格布局里有 habit 块，若模型把"美式咖啡"当成居住事实（例如"我住的小区喝美式"），
按现定义**不判污染**。→ 我建议把词表扩到"任何非 home 块"（我在 §1.1 已经按扩展写了），
但这**是我的扩展，不是预登记**：若本轮真出现 habit 串被归属，只能记"预登记词表外的观测，不参与判定"。

**H5（门禁与预算的交互没写）**：预登记说"唯一变化 n_predict 24→64"。但 control 门禁也是走 ask 的
（probe:527 用同一个 N_PREDICT），若执行者只在答案问句上改 64、门禁仍 24，则装置变了两个字段。
→ 必须交：control 的 n_predict 实际值、control.questions 的答案长度、control_ok。
四格的门禁在 14B 上是 24，若本轮门禁是 64，则 control_ok 的可比性要单列。

**H6（越界归因）**：§4 映射表"出现污染 ⇒ 规模使失败阈值上移的支持度**下降**"。
这是跨模型的程度判断，且"支持度"没有量化定义，违反预登记 §6 自己写的"只比有无、不做数值比较"精神。
→ 只许记"该现象在 7B@64 亦出现"；升降的判断留到有共同的、非饱和的量化判据之后。

**H7（两跑不一致没规定）**：§3 只写"至少 1 跑出现即成立"，没写两跑一个污染一个干净时记什么。
→ 我补：仍按"至少 1 跑"判成立，但必须并列两跑结果并标"不稳定"，且该格的不确信度上调。

（另外两条小提醒，不算漏洞：预登记没要求交**块 sha 自检**，而 7B 的四个块 sha 是
home ba92d730… / project 48825f8d… / habit 6c210314… / pp18 32306e8a…（7B 侧，我 7B 时代核过的值）；
