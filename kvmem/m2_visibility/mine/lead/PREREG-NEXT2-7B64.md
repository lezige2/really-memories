## 3 判据（写死，非饱和）
### P 判据 · 污染（本轮**首次作为预登记判据**）
- 定义：对 home 的问句「我住在哪？」，答案中若出现 **slot4 块特有的事实串**（pp18 => 「蓝鲸」或「三月十四/三月十四号」）**且该串被当作居住类事实回答**（出现在「我住的小区叫…」「我的地址是…」这类归属句里），记 **污染**。
- 成立条件：2 跑中**至少 1 跑**出现。
- 不计污染（记「引用」）：该串只出现在与 home 无关的续写里（例如模型自问项目上线日期）。
- 前提校验：该串必须在 slot4 块文本里存在、在 home 块文本里不存在。
- **来源声明**：本判据是从 14B 的 F 观测**事后提炼**的，但此刻写死后就冻结，对本轮而言是预登记。

### F 判据 · 可读性形态（先判它，再判污染）
- 崩坏：整段为下划线填空模板、或退化复读（同一句反复）。
- **若判为崩坏 => 污染判据不适用**，该格记「未测出·判据不适用」，**不得记为「无污染」**。

## 8 修正案（2026-10-25 01:20，收到盲写清单 BLIND-CHECK-7B64.md 之后、**任何 7B64 数据回来之前**写下）

检测员对我这份预登记提了 7 条漏洞。**全部接受**，逐条记：

### H1 采纳（最要紧）：崩坏是**分段**不适用，不是整段
- 原写法「崩坏 => 污染判据整段不适用」会丢掉「先答一句正常、再滑进模板」的样本，而 64 token 恰恰最可能出这种样本。
- 改为：崩坏起点**之前**的句子照判 P；崩坏起点**之后**不参与 P。若崩坏起点在首句之内 => P=NA。
- 注意这个改动会**更容易判出污染**（判据变宽），对「7B 是否也有渗入」是保守方向，可接受。

### H2 采纳（我的因果说反了）：E 也污染并不说明判据有缺陷，而是**来源不可辨识**
- E 的 slot4 是 project 块的**逐字节副本**，「蓝鲸」同属两块 => E 污染时无法归因是 slot4 还是 project 干的。
- 正确记法：**污染 = 是，来源 = 不可辨识**。原写的「停手报我 / 判据失效」作废。
- 由此：F 格的污染只能在「副本格干净」时才能指向 slot4 的改写形态。

### H3 采纳（缺一档）：24 是 64 的前缀且形态不变 => 欠功率，不是判据不适用
- 新增结论格：若 24 答案是 64 答案的字面前缀且崩坏形态相同 => 记「**未测出·欠功率（预算未改变形态）**」。
- 这一档与「判据不适用」不是一回事：后者是崩坏吞掉句子，前者是连崩坏都没变。

### H4 部分采纳（词表扩展是我的，不是预登记的）
- 判据词表扩到「任何非 home 块」的串（project 族 / habit 族），检测员已按扩展写；
- 但若本轮真出现 habit 串被归属成居住事实，只能记「**预登记词表外的观测，不参与判定**」。不许事后升格为判定量。

### H5 采纳（门禁与预算的交互我漏了）
- control 门禁走的是同一个 N_PREDICT（probe:527），所以 n_predict 改成 64 时**门禁答案也会变长**。
- 必须交：control 的 n_predict 实际值、control 各问答案长度、control_ok。四格 14B 的门禁是 24，若本轮门禁是 64，则 control_ok 的可比性单列。

### H6 采纳（我越界归因了）
- 原写法「出现污染 => 规模使阈值上移的支持度**下降**」是跨模型的程度判断，且「支持度」无量化定义，违反我自己写的「只比有无、不做数值比较」。
- 改为：只许记「该现象在 7B@64 亦出现 / 未出现」。升降判断留到有共同的非饱和量化判据之后。

### H7 采纳：两跑不一致
- 仍按「至少 1 跑出现即成立」判，但必须并列两跑各自的 P/F，标「不稳定」，该格不确信度上调。

### 执行顺序（也按检测员的）
- **先算 F（形态），再算 P（污染）** —— F 决定 P 是否适用。派单编号 1=P、2=F 只是编号顺序，不是执行顺序。
