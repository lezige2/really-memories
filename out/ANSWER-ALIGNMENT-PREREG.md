# 答案-问题对齐（Answer-Question Alignment）预注册 v1

> 状态：预注册，未写码。放在 verifier 之后、返回用户之前；只判一次；失败回固定拒答模板，**不重新生成**。

## 1 目标与边界

- 解决：answer 有块支持、但**块不对题**（如问车牌保险到期日，答出车牌号；问储物柜初始密码，答出当前密码）。
- 不做：不判断事实真假、不替代 verifier、不调模型、不改写答案。
- 位置：`verifier v1 → alignment → 返回`；flag `--answer-align` 默认 **off**。
- 失败：`False` → 固定拒答模板；`True` → 原答案。
- 审计：每次记 `trace_id/query/asked_subject/asked_predicate/answer_slot/decision/reason/fail_open`。

## 2 三级漏斗

### 第一级：主体槽位
- 从 query 抽 asked subject（默认 self；显式“阿泽/刘敏/我媳妇”等）。
- 从 answer 抽 answer subject；从**本次挂载块**抽 block subject。
- 规则：
  - query 显式主体 ≠ answer/块主体 → FAIL；
  - query 是代词（他/她/那个/那辆）→ 用**本次 query + 本次挂载块**找先行词；找不到 → PASS + `unresolved_pronoun`；
  - 不引用历史对话。
- 豁免：代词且有明确先行词 → PASS。

### 第二级：谓词槽位
- 从 query 抽 asked predicate；同义词表先归一（单位=公司、座机=电话、车牌=牌照…）。
- 从 answer 按 **asked predicate 抽值**：
  - 抽到值 → 校验值形态/槽位；
  - 抽不到，但 answer 出现**别的槽位**的值 → FAIL；
  - 两样都没有 → PASS（fail-open）。
- 不按“出现手机号格式就 FAIL”整段扫；只查被问槽位，避免误杀“车牌 X，电话 Y”。

### 第三级：数字/值存在性
- query 含明确值（如“尾号 8899 对不对”）→ answer 必须含该值。
- 归一：全角→半角、去分隔符；中文数字 ≤4 位转阿拉伯；尾号按后缀 ≥4 位；日期统一 (月,日) 或 ISO 双形态；单位不自动换算（除非两侧都有）。
- 例：“对，是 8899”含 8899 → PASS；“是 8898” → FAIL。

## 3 Fail-Open 边界

- 仅当**完全抽不出 asked subject 或 asked predicate** 时放行，并记 `fail_open=true`。
- 抽出了但不确定 → **不放行**，按规则判。
- 20 负例上 `fail_open > 2` → 判“门没在工作”，不接默认。
- 谓词/槽位表按**通用槽名词汇**预先声明（车牌/保险到期/有效期/到期日/密码/初始密码/验证码/IMEI/卡号/尾号/公司/工位/会议号/疫苗编号/邮编…），**不许照 20 条逐条加**；覆盖不到先改表，不拿 fail-open 兜底。
