## 2 为什么先 P 再训

- P 若过门（acc≥95%、灾难错 0、真歧义不判 correct），**不需要训练**，省下 adapter 部署死结；
- P 不过，训练才有明确目标；训练数据用 P 的错例做定向增强，而不是盲训 6k。
- 但租期固定：即使 P 过，也建议用剩余窗口跑一次**小规模 LoRA 对照**（2k 子集），确认"训练是否比 prompt 更好"，否则以后没有窗口。

## 3 主动性（用户点名）

- 训练不能替代运行时触发器：没有"何时开口"，模型再会写也无法验收。
- 今晚先出 `AUTONOMY-TRIGGER-SPEC`：触发条件（时间/事件/沉默时长）、静默期、误报预算（≤1 条/周）、离线判定器、失败回退。
- 明早若时间允许：用 14B prompt 做 D 类基线（不给训练），看模型是否已有主动表达能力；不够再谈 adapter。
- 不把"空 user 探针"当真实主动性。
