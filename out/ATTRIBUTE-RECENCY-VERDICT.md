# attribute-recency 真实 MT20 5×2 · 封存结论

## 结果（2026-11-06 02:27）
| 臂 | pass | rate |
|---|---|---|
| off | **54/100** | 0.540 |
| on | **48/100** | 0.480 |

- **on 低于 off 6pp**；
- **V9MT05 手机 5/5 → 1/5**、**V9MT06 5/5 → 2/5**，命中“4–5→0–2”崩落红线；
- V9MT04 4/5→5/5；其余 17 条两臂一致；
- attribute 触发率 **4/20 = 20%**（仅 03–06），≤30%，不是触发面过宽；
- 失败形态：on 对 05/06 报 `kept=[3,12,22] / hidden=[21]`，隐藏旧号仍答错/回退。

## 与对抗集的矛盾
- 构造串味集：off 4/20 → on 20/20（phone 10/10）；
- 真实 MT20：phone 5/5 → 1/5。
- 说明真实库的 phone 多值关系（21 旧、22 新、3/12 干扰）与构造集不同；只隐藏 21 不足以让答案正确，可能还移除了必要上下文。

## 判定
- **门不通过**：on 低于 off、phone 崩落；
- **attribute-recency 封存**：默认 off，不接服务默认，不再换属性重开；
- 这条是检索线第 N 次失败，按 B 预注册“信号不足封存”；
- 不写“质量提升”；真实 MT20 仍以 5× 全开/全关为记录，质量边界不变。
