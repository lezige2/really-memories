# K4 预注册：生成层事实 schema（分两步）

前提：**K4 必须等 K3′ 结果；一次只动一个变量。**
K4 第一步只做 prompt schema；verifier retry 第二步单独预注册。两个机制不合并。

## 硬约束
1. `[历史/已过期]`、`[当前最新状态]` **绝不能写进块文本**：
   - 只作**运行时装配标记**，按 created_at 即时算；
   - 不落库、不改 memory_block、不改 sha/溯源。
2. “冲突以 created_at 最新为准”若进系统提示，属常驻行为变更，必须 `--conflict-schema` flag 化，默认 off。
3. verifier retry 只做一次；必须记录被剔除的值、块 id、原答案、重试答案。

## 第一步：prompt schema（只此一项）
- 同属性多值时：旧块运行时标 `[历史/已过期]`，新块标 `[当前最新状态]`；
- 新块放 prompt 末尾、贴近问题；
- 显式规则：冲突以 created_at 最新为准，历史只作背景；
- 不改块文本、不改答案生成路径其他部分。

## 门（预注册，缺一不过）
1. MT20 5× paired：on 不低于 off；
2. 无 case 4–5/5 → 0–2/5；
3. 81/extra 不回归；
4. 逐 case 记实际装配顺序/标签，证明标记生效；
5. 触发率与旧值出现率记录。

## 第二步：verifier retry（另行预注册）
- 仅第一次 fail 后重试一次；
- 重试 prompt 剔除被拦旧值/加指令；
- 记录剔除值/块；
- 单独门，不与 schema 合并。
