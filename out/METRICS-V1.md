# v1 指标口径与 flaky 清单

## 1 不再用单次 MT20 作声明
- 单次 MT20 只记录，不作“通过/不通过”；
- 正式看 **MT20 5× 通过率 + 逐 case 稳定性**；
- 任何 case 从 4–5/5 掉到 0–2/5 → 系统性回归；
- 只有“总体差 ≤5pp 且无 case 大幅掉”才允许默认开。

## 2 已冻结 flaky
| 项 | 证据 | 处理 |
|---|---|---|
| L05 | 5× 2/5；20× 基线 18/20、P1 16/20 | 从 extra 分母剔除，单列 |
| V9MT04 | off×100：1/100 fallback；同输入 23 种答案形态 | 入 flaky，单列 1% fallback |
| V9MT17/18 | 早前两臂皆 fail，旧值/措辞 | 已知答案层缺陷 |
| V9MT08 | 全开单次 fail，配对 5× 各 5/5 | 偶发，单列 |

## 3 固定指标
- 81：81/81（默认路径）；
- extra：**17/19**（剔 L05；失败集 L07/L09）；
- MT20：5× 通过率 + 逐 case；单次不声明；
- 延迟：P50/P95；200 行写入 P50 0.4s/P95 0.57s（cap on）。

## 4 禁止
- 用单次 11 vs 10 宣称回归/不回归；
- 把 CI 跨 0 读成“没差异”（是无证据）；
- 临时扩 flaky 清单；只允许已冻结项。
