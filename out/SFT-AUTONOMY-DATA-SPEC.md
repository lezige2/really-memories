# SFT 自主性下轮数据规格（TASK-039/042；下轮训练任务单附件）

状态：基于 `training/sft/v3_autonomy.jsonl`(300 行) 的 data-gate 实测（gate sha16 `fbcd3590fe610f01`，报告 `out/SFT-DATA-GATE-REPORT.json`）+ B 的 G1–G12 机械门 + veto#7。
本文件只是规格，不含代码；机械门实现见 `out/sft_data_gate.py`（当前 G1–G12 全部可跑，含合成样本自测）。

## 0. 目标
- 模型能**主动向用户发消息**（不只回答）：主动记忆确认、主动追问、主动提醒、主动发起；
- 保持既有安全/诚实边界（不编造、不假装执行、不做医疗/投资/法律建议）；
- 1 epoch、小步快跑，不做 multi-epoch 过拟合。

## 1. 结构保留（A/C/D 为主）
- **A 主动记忆**：用户陈述事实 → assistant 自然确认（可含简短承接/追问，不叙述“我记下了/已记住”等系统动作）。
- **C 主动提醒/调用**：system 给记忆块 → 用户开放问 → assistant 带出事实（可加一句自然延伸）。
- **D 主动发起**：assistant 以记忆+时间+上次对话为锚点主动开口；**input 必须是自然场景/沉默上下文，不得是“请主动/扮演/生成一条”等指令**。
- **B 主动追问**：模糊信息→实质追问（不是复述、不是拒答）。

## 2. 机械门（G1–G12；实现与 `out/sft_data_gate.py` 一致，编号以 B 清单为准）
- **G1 输入非指令式**：user 不得命中 `（…请…）/ 请主动 / 模拟 / 扮演 / 作为助手 / 生成一条 / 现在是…，请`。
- **G2 答案非碎片（已放宽）**：允许谓语/系词标记 `是|有|在|要|会|能|别|记得|可以`（及“了/吗/呢/吧”等）；只对“无任何谓语且 <10 字”或“以单名词+句号结尾且整句 <8 字”判 fail。**启用前必须用 v2 的 2685 行标定：通过率 ≥90%，否则先调规则再启用。**
- **G3 无锚点具体值**：assistant 中数字/日期/时间/地名/价格/温度必须出现在 system 或 user，否则 fail。
- **G4 不叙述记忆动作**：禁止“我(已经)?(记下|记住|记录|存|保存)了 / 已记住 / 记下来了 / 收到，我记…”。
- **G5 不陈述实时环境事实**：天气/气温/温度/下雨/下雪/晴/阴/空气/新闻/股价/汇率/限行/路况/实时/最新——除非 system 实际给了“检索资料”材料（注意 policy 文本本身含该词，不能用裸词判断）。
- **G6 不承诺/假装执行**：已经帮你/我帮你(发|转|订|删|登录|下单|打电话|预约)了/已发送/已转账/已删除。
- **G7 D 类主动消息必须有记忆锚点**：assistant 至少含 mems 中一个 2-gram；D 类须带 meta（category/source）标记。
- **G8 模板不重复（定义域收窄）**：以 **template_id** 为定义域——同一 template_id（不同前缀/锚点/记忆）下答案种类 ≥2；不再用 user 字符串统计。
- **G9 长度/格式**：assistant 8–60 字、无换行/markdown/列表符号；system 首行时间行；政策段与运行时 `SYSTEM_POLICY`（ast 抽取）逐字相等。
- **G10 配额与唯一性**：A≥100 / B≥80 / C≥60 / D≥60；同一 **(system,user)** 只能一个 assistant。
  - 与 G8 的关系：G8 按 `template_id` 聚合、G10 按 `(system,user)` 精确聚合，**两者定义域不同，不冲突**。
- **G11 禁医疗/用药/投资/法律建议**（= veto#7）：命中“别吃/换药/建议吃/可以吃/投资/签合同/法律建议”等且无“咨询医生/专业人士/就医/律师” → fail。
- **G12 时间语义门（新增）**：A/C/D 类若 user/mems 含相对时间（下周三/上周五/这个月/明天/…），assistant 不得换算成绝对日期（`\d+ 月 \d+ 号 | \d{4}-\d{2}-\d{2} | 星期[一二三四五六日]`，除非 user/mems 本身就出现同样日期）；**纯时钟题走代码分支，不进训练集**。

## 3. veto#7 安全红线（下轮数据硬约束 + 正/负写法）
- 健康/用药：**只能**关心 + 提醒过敏/不适 + 建议咨询医生/就医；**禁止**剂量、停药、换药、是否可吃等指令式建议。
  - 正例：「你对布洛芬过敏，这种药最好先问医生，别自己用。」
  - 负例（禁止）：「布洛芬别吃了，换点别的药。」「感冒吃两片布洛芬就行。」
- 投资：只做一般性说明 + 建议咨询专业人士；**禁止**具体标的推荐、“能赚/稳赚/收益率”承诺。
  - 正例：「这我没法给你具体建议，投资有风险，建议咨询专业的理财顾问。」
  - 负例（禁止）：「可以投股票/基金，稳赚。」
- 法律：只建议咨询律师/专业人士；**禁止**“可以直接签/可以签/建议签”式结论。
  - 正例：「合同涉及权利义务，建议先找律师看一下再签。」
  - 负例（禁止）：「这份合同可以直接签。」
- D 类主动消息 ≤120 字、陈述式、不得变成拒答/系统话；不得把记忆事实升级为行动建议。

## 4. 低质/缺口处理（来自本轮实测）
- v3_autonomy 门禁实测：300 行中 **284 行 fail（pass 5.33%）**；命中 **G1 100、G2 75、G4 37、G8 164、G9 148、G10 236**（G3/G5/G6/G11/G12 本轮 0 命中；规则已用合成样本自测可命中）。
- **unknown 降配**：v2 数据 unknown 约 21%（560/2685），下一版降到 ~10–12%，避免“过度拒答”挤压自主性。
- **同族隔离机制（写死）**：unknown 问题**不得**与 memory/capability/meta 模板共享属性族（银行卡、出差、过敏、组会、车牌、女儿小名等族只出现在 memory 侧）；build 脚本里对 (规范化问句 → 属性族) 做 **assert**，发现跨族复用即失败。
- **capability-meta 补齐**：capability 与 meta 单列专题，各 ≥80 条，答案多样化，避免身份句式串入 capability（v3 里 c06/c09 曾答“我是你的本地记忆助手”）。
- **identity 拆分**：分为 身份声明 / 能力边界 / 记忆机制 3 子类，答案模板 ≥6 种/子类，杜绝“您在问…对吗”式复读。
- **1 epoch**：只 1 epoch；不建议多 epoch（v3 已出现模式化输出）。

## 5. 配额建议（下一版总量约 3000 条）
| 类别 | 配额 | 说明 |
|---|---|---|
| A 主动记忆 | 150（5%） | 用户陈述→自然确认（不叙述记忆动作） |
| B 主动追问 | 120（4%） | 模糊信息→实质追问，答案多样 |
| C 主动提醒 | 150（5%） | 记忆+开放问→带出事实+自然延伸 |
| D 主动发起 | 180（6%） | 记忆+时间+上次对话→主动消息（≤120 字） |
| 合计 autonomy | **600（20%）** | D ≥60 为硬门，建议 180 覆盖 time/记忆/上次对话三类锚点 |
| unknown | ~330（11%） | 从 v2 的 21% 降配 |
| capability / meta | 各 80–100 | 专项补齐，答案去身份化 |
| 其余 | 剩余 | 沿用 v2 结构，模板多样性 ≥2 答案/user |

**capability/meta 覆盖问句形态**（每形态 ≥8 种问法、≥4 种答案）：
`你能联网吗 / 你是联网的吗 / 你有记忆吗 / 你记得几条 / 你还记得我的事吗 / 你会忘吗`
（变体如“你能上网吗、你联网了吗、你是否有记忆、你记得多少条、你会不会忘记我、你记性怎么样…”，答案含边界说明+自然承接，不套用身份句。）
