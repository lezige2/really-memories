# P2 检索重排规格（coarse → K2/time → top4）

> B 裁定：**P2 先于 P0**。P0 的“过期不挂”只在候选池内生效，池结构一变 P0 数字作废；P2 直击 over-merge 根因。
> 本文件先写规格与预注册，**不改产品默认**；实现用 flag `--rerank-pool` 默认 off，一行回滚。

## 1 现状问题

```
全库 → 全局 K2 family 去重 → 其它族 topk 填充 → 挂 4 块
```
- K2 在**全库**按 family 合并，200 块时 12–28 个同族/不同主体被合并，recall 0.711→0.368；
- count 门（>50）只是把 K2 短路，不是结构修复；
- fill 会把其它族块塞进候选，造成跨族串味（L05/V9MT05 类）。

## 2 目标管道

```
query
 → 粗排 topK_coarse（10/20，纯检索，不跑 K2/time）
 → 候选池内：
      a) time 过滤（created_at；一次性会议/出差过期；periodic 豁免）
      b) K2 精排（只在池内按 family/subject 去重；池外不感知）
 → 取最终 top4（现有 fit_budget 截断）
 → 14B
```

- **K2 只在池内生效**：不再有“全库 family 合并”；
- 池外块不参与 K2，不因“同族”被隐；
- 粗排池必须足够大：先测 `recall@10/20`，若 target 进不了池，P2 直接失败，不靠 K2 补救；
- time 过滤只作用于池内；归档/回填块不解析相对日期；
- 不把记忆原文拼进 prompt，仍走 KV 块。

## 3 预注册（B 定）

| 项 | 门槛 |
|---|---|
| 粗排池 recall@20 | **≥0.95 且 target 进池 ≥38/40**（@10 仅描述，不作门） |
| 200 档 recall@4 | **≥0.711**（不低于 K2-off） |
| direct recall | **≥0.95** |
| 误隐（同 subject+predicate 被隐） | **=0** |
| chain_last（单列，防 P0 指标漏项） | **≥ K2-off** |
| P50 | 20 档 ≤13.6×1.2=16.3s；50 档 ≤14.3×1.2=17.2s；200 档 ≤15.3×1.2=18.4s |
| 旧值泄漏 | 不升（同期 K2-off 比） |
| 20/50 档 | 81/extra/MT20 不回归（81 81/81、extra≥19、MT20≥18） |
| 回滚 | flag off 后行为与现网逐字一致 |

- 20/50/200 三档都跑；51–199 仍标未验证；
- 若 200 不过，P2 失败，不启动 P0，不加补丁；
- **若 pool recall 达标但 top4 recall 掉，判精排有问题（不是池），先修精排，不得放宽门槛**；
- 若 P2 成功，重新评估 K2 的“≤50 门控”是否还需要。

## 4 实验设计（离线，先不改服务默认）

1. 固定 20/50/200 三库与同一 40 题；
2. 臂：
   - A：现状（K2 off）
   - B：现状（K2 auto）
   - C：P2 topK_coarse=10
   - D：P2 topK_coarse=20
3. 先测粗排池 `recall@10/20`；池召回不够就不进入重排；
4. 指标：recall@4、direct、pass、误隐、泄漏、P50/P95、fit_budget 丢弃、5xx/lock；
5. 全部离线 CPU 纯函数 + 现有 RESULT 挂载复算；不调模型、不写库。

## 5 风险

- 粗排池太小 → target 进不了池，P2 变差；所以先测 pool recall，不达标直接停；
- 池内 K2 仍可能 over-merge（多主体），但影响被限制在池内，且可用 subject 键进一步收敛；
- time 过滤可能误杀；periodic 必须豁免；
- 复杂度：粗排 O(N) 仍存在，但 K2/time 只 O(池)；不能宣称“O(1)”整体，除非索引支持。

## 6 明确不做

- 不改 `created_at`/原文；不把记忆文本拼 prompt；
- 不做 LRU/归档（P1 另立 spec）；
- 不做 P0 event_date（P2 过门后再启动）；
- 不默认开启、不切默认、不 push。
