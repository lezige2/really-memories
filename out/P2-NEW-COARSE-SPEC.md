## 2 设计

1. **种子**：现有 no-gate 词面 top50（hit-count 排序，只当候选集，不参与最终排序）。
2. **分词**：CJK unigram + bigram + 拉丁词；query/doc 同法。
3. **BM25**：k1=1.2、b=0.75（N=190 文档，avgdl 实际统计）。
4. **加分（精确命中，不做同义扩写）**：
   - 实体精确命中（query 含该块开头的人名主体）**+3.0**；
   - 谓词精确命中（车牌/手机/会议/老家/座位/公司/银行卡/颜色/猫/狗 的 query 线索 ↔ 块内对应词）**+2.0**；
   - 值形态匹配（会议日期、手机 11 位、车牌形态）**+0.5**。
5. **重排**：对 50 个种子逐条打分，`total = BM25 + entity + predicate + shape`，取 **top20** 为候选池；**无 coverage 闸、无空池清空**；同分按 id 升序。
