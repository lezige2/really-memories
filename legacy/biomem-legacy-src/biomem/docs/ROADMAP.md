## 验收指标与验证方式

| 指标 | 目标 | 验证方式 | 现状 |
| --- | --- | --- | --- |
| 召回相关性 | 提到旧事能取到相关卡，不大量错配 | `/recall` 看通道与分数；跨会话问猫名/项目 | 通过（宠物卡排第一，注入 1–3 张） |
| 人设一致性 | 语气、边界稳定 | 多轮聊天观察；`/persona` 检查 | 通过（系统提示 + 独立程序记忆） |
| 情感连续性 | 共同经历有延续感 | 隔会话追问旧事 | 通过（语义卡 + 情景卡） |
| 遗忘合理性 | 低权重衰减，不无限膨胀 | `test_forgetting`；`/decay --dry` | 通过（单测归档 + 语义豁免） |
| 资源占用 | 16GB 不频繁 swap；10GB 显存不爆；延迟可接受 | `scripts/bench.ps1`；任务管理器 | 通过（7B Q4，8K ctx，约 5–6GB 显存） |
| 写入门控 | 不每句都写；重复不重复建卡 | `/why`；`test_clause_split` | 通过 |
| 可回溯 | 能解释为什么记得/忘了 | `memory_event`、`/why`、`/cards` | 通过 |

## 已知缺口（按优先级）

1. **语义向量**：当前向量是词形哈希，同义改写召回弱。接入 bge-small-zh 后应显著改善。
2. **后台巩固**：现在是同步调用，长对话时会在某轮卡一下；应移到后台线程并加空闲判断。
3. **工作模式标记**：结论「待确认」需要写进卡片元数据，避免工作推断污染长期事实。
4. **多用户/多角色**：当前 `subject` 固定为「用户」，多人共用需扩展。
5. **性能**：每轮全表扫语义卡做冲突检测，卡片上千后需要索引（`predicate` 列或单独表）。
