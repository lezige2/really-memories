## 2 真号验收清单（扫码登录后逐项勾选）

- [ ] **登录**：NapCat 扫码登录成功，反向 WS 连上 bridge，bridge 日志出现连入记录（无 401）。
- [ ] **群 @ 问答**：群内 @机器人「你好」→ 固定问候句（`state=smalltalk`，不调模型）。
- [ ] **群 @ 无记忆事实**：「我明天要去哪里出差？」→ 固定拒答（`refused=true`），不得答成旧上下文。
- [ ] **私聊有记忆事实**：「我的车牌号是多少？」→ 返回记忆中的 `京A88888`（`state=memory_hit`）。
- [ ] **`/remember` 后追问**：`/remember 我每周三下午三点在 3 楼开会` → 再问「我几点开会？」→ 答案含「三点/15:00」；重启服务后仍可答。
- [ ] **拒答纪律**：无记忆且非对话内的事实问句 → 拒答；对话内追问 → 正常回答（不误杀）。
- [ ] **日志与隐私**：`kvmem/qq_logs/bridge-*.jsonl` 只有元数据（时间/群/命中/命令/错误类型），**无消息正文与回答正文**；`/log` 会话日志按 redacted 模式可审计。
- [ ] **断线重连**：停掉 NapCat（或 bridge）再恢复 → bridge 自动重连（`reconnect` 计数增长），期间消息不崩服务、不重复回复。
- [ ] **超时/长答**：>600 字回答按条切分（≤4 条）且末条带省略；bridge 超时回执可见，不静默。
- [ ] **命令面**：`/status`、`/memories`、`/forget`（管理员限制如配置）、`/help` 均可用。
- [ ] **回执留痕**：验收时间、NapCat 版本、bridge/service 版本、群号/机器人号（脱敏）记入验收回执，不写 token。

## 3 已知边界（如实披露）

- 本节只证明链路与产品行为可用，**不证明**判据误判/漏判率（H1 结论只在 b5 结果件）。
- NapCat/QQ 属外部链路：风控、封号、协议变更不在本验收范围；token 泄露需立即轮换。
- 机器链路验收（模拟客户端）≠ 真号验收；真号未登录前，状态一律记“未接上（真号未登录）”。
