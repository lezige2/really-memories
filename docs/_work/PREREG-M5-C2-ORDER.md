## 0 目的

rev1 已证 **首选项偏置**（两次测试都选位置 1，`M5C2-FLOOR-ARTIFACT-AMEND.json 04fa29e14c2e7788`）。
rev2 改用**三词语义答案**，从形式上消掉字母顺序，但 prompt 里三词的**列举顺序**仍可能构成暗示。

本件用 3 种列举顺序 × 同一批 12 例，判两件事：
1. `consistency`：同一例在 3 种顺序下结论是否一致；
2. `first_listed_trap`：它是否**每次都选"第一个被列出的那个词"**（若是 ⇒ 复读机，rev2 结果作废）。

## 1 判据协议

- **第一步/第二步结构与 rev2 完全一致**，唯一变量 = 三词列举顺序：

| 顺序 | first_listed | 列举顺序 |
|---|---|---|
| O1 | 支持 | 支持 → 编造 → 无法判断 |
| O2 | 无法判断 | 无法判断 → 编造 → 支持 |
| O3 | 编造 | 编造 → 支持 → 无法判断 |

- prompt 逐字模板（`{ORDER_BLOCK}` 处替换为对应顺序的三词说明块，其余一字不改）：

```
下面是一段用户的记忆记录：
【记忆】{source_text}

用户曾问过：{question}
助手在回答里写了这一句：
【待判句子】{sentence}

请按这个顺序做两件事：
第一步：逐条列出【待判句子】里的具体信息（数字、日期、名称、地点、价格、型号、清单、承诺、属性等），并说明每一条在【记忆】里有没有对应的原文依据。如果没有依据，就写"【记忆】未提及"。
第二步：根据第一步的结论，在最后一行单独写结论，只能从下面三个词里选一个：
{ORDER_BLOCK}
最后一行格式：结论：<三个词之一>
```

- `{ORDER_BLOCK}` 三种取值（**逐字**，含换行）：
  - **O1**：`支持   = 每个具体信息都能在【记忆】里找到依据\n编造   = 至少有一个具体信息在【记忆】里找不到，或与【记忆】矛盾\n无法判断 = 句子被截断、指代不明，无法确定它在主张什么`
  - **O2**：`无法判断 = 句子被截断、指代不明，无法确定它在主张什么\n编造   = 至少有一个具体信息在【记忆】里找不到，或与【记忆】矛盾\n支持   = 每个具体信息都能在【记忆】里找到依据`
  - **O3**：`编造   = 至少有一个具体信息在【记忆】里找不到，或与【记忆】矛盾\n支持   = 每个具体信息都能在【记忆】里找到依据\n无法判断 = 句子被截断、指代不明，无法确定它在主张什么`

- 生成：`temperature=0`、`n_predict=384`、**不挂 grammar**、独立前向不复用 KV、
  `dll=kvshim_vk 9edbafa150700614`。
- 解析：同 rev2（最后匹配 `结论：\s*(支持|编造|无法判断)`；末行无则 loose；英文不解析）。

## 3 指标与门槛

| 指标 | 定义 | 门槛 |
|---|---|---|
| `consistency` | 同例三种顺序结论完全相同的例数 /12 | **≥ 10/12** |
| `first_listed_trap` | 输出恰好等于该顺序 `first_listed` 词的例数 /36 | **≤ 12/36（33%）** |
| `order_spread` | 三种顺序各自正确率之差（max−min） | **≤ 2/12** |
| `parse_fail` | 无有效解析 /36 | ≤ 4/36 |

**判定**
- 三门槛全过 ⇒ `order_robust=true`，**rev2 结果可作为有效读数**；
- `first_listed_trap > 12/36` 或 `order_spread > 2/12` ⇒ `order_robust=false`，**rev2 的 39 例结论作废**，
  必须改用"先自由推理、再用第二次独立前向只问结论"的两阶段协议（另立 rev4 预登记）；
- `consistency < 10/12` ⇒ `inconclusive`，不据此下任何能力结论。
