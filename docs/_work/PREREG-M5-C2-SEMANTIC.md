## 1 路线 R1：NLI 小模型（CPU，可复算）

- **判据形态**：输入 `(记忆源文块, 句子)` 对；输出 `entailment / neutral / contradiction` 三分类。两段式：① **事实性门**（沿用 v2.3 的 A/B 分级判「这句话是否断言可核事实」，无断言 ⇒ `no_fact`/`undecidable`）② 对断言句做 NLI。
- **映射**：`entailment → supported`；`contradiction → unsupported`；`neutral → undecidable`（**不**记 `no_fact`：判不了就是判不了）。
- **候选实现**（须固定到具体 checkpoint + sha，不得事后更换）：`bge-reranker` 类 / `mDeBERTa-NLI` 类中文小模型。**优点**：便宜（CPU）、可复算、**无自我偏好**（不是被评模型）；**缺点**：中文小模型在**长事实对**上的准确率**未知**，必须先做能力标定。
- **能力标定（写死）**：只用 **(c)** 或**另造校准集**（另立件、独立冻结）；**不得用 (b2) 的 510 句做标定**（会消耗样本外集）。标定件须报：校准集上的漏判/误判 + 负对照（§3），达标才可进入 (b2)/(b4) 验收。

## 2 路线 R2：14B 自我判据（LLM-as-judge，GPU）

- **判据形态**：把「记忆源文 + 句子」给 `DeepSeek-R1-Distill-Qwen-14B-Q4_K_M`，问「这句话是否被源文支持？」，输出 `supported / unsupported / undecidable`（**必须允许弃答**）。
- **优点**：语义能力强，能处理散文型编造、指代与部分改写；**缺点致命：自我偏好**——同一模型判自己的输出会**系统性偏宽**（把「像真的」判成 supported）。
- **对照臂（必须做，不是可选）**：① **异模型判据臂**（换不同模型/不同家族判，报两臂一致率）；② **负对照臂**（正确句子配**随机无关源文**，判据应大量判 `unsupported`）；③ **独立盲标抽样复核**（≥50 句，人类/独立盲标，报一致率）。
- **算力**：510 句 × 正/负对照各 1 次前向 ≈ **20–40 分钟 GPU**；安全门同 (b2)（VRAM ≤8.0、8.6 熔断、单场景 ≤900 s、父不发信号、host gate）。**`needs_gpu=true`。**

## 3 防作弊要求（写死；不满足者**不得作为验收判据**）

- **负对照误支持率（新增硬指标）** = #{正确句子 × 无关源文 且 判据判 `supported`} ÷ #{负对照句}，**必须 ≤ 10%**；报分子/分母。防「什么都判 supported」。
- **正对照通过率** = #{正确句子 × 正确源文 且 判据判 `supported`} ÷ #{正对照句}，**报告并要求 ≥85%**（与误判率 ≤15% 对称）；正负对照必须**同时**报，只报其一无效。
- **`self_preference_control` 必须存在**：至少包含 §2 的 ①② 两臂（③ 为推荐）；缺任一 ⇒ **不得**把该判据用于验收、不得报「通过」。
- **禁**：只用被评模型自评；只报正对照；用 (b2) 结果设计 prompt/选模型后仍把 (b2) 当样本外（须另立 (b4)）。

## 4 验收线（沿用 B2 §4 + 负对照新增项）

- 样本：≥8 题、**≥150 非空句**（B2 §2 句计数口径）；两率及对照分母均 ≥10。
- **通过**：漏判率 ≤ 20% **且** 误判率 ≤ 15%（主口径同 B2 §3 不对称定义）**且** 负对照误支持率 ≤ 10% **且** 正对照通过率 ≥85%。
- **未通过**：任一超线。
- **未接上**：装置/门/熔断/样本量不足/标注不可靠/**负对照缺失或不可信**。
- 一致率口径（修正 B2 缺陷 `prereg_defect_three_way_metric=true`）：**标注可靠性 = ADJ–REVIEW 两两一致 ≥80%**；judge 不参与一致率（judge 与金标的一致就是两率本身）。
- **判据作废**（LEAD 裁）：新判据若仍在 ≥50% 漏判句上重复同一机制 ⇒ 判「判据仍不成立」，不得报「通过」。
