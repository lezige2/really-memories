# M4-C 外请教要：验收判据自身的判别力

## 一、这是什么
llama-mem / kvmem：把**长期记忆存在 KV tensor 里**，而不是 prompt 文本里。被测对象是 llm 的 kv cache 内存管理（lease / seq / cell 三层），运行环境 AMD RX 6750 GRE 10GB + Vulkan，模型 DeepSeek-R1-Distill-Qwen-14B Q4_K_M。

**M4-C 要回答的问题一句话**：把某个站点（site）的 `leases.reset(...)` 调用删掉，会发生什么？—— 这是在检验「这些内存管理机制是不是真的在承重」。

## 二、现在的状态
**零条验收读数。**

不是没跑。跑过一次，五份产物全是 `exit 5`（仪器坏）。原因是：**当时写日志的那个函数体是空的（只剩 docstring），一条日志也没写出去。**

之后每一轮都在修链条上别的环，而没有再跑。链条是：

    被测对象 → 判据 → 日志通道 → 产物 → 快闸 → 复核者

## 三、真正的问题：判据坏掉之后，看起来与好的时候一样

这不是一个缺陷，是一族。今晚抓到十种形态，每一种都曾让一个坏掉的判据显示为通过、或显示为红而红错了理由：

| # | 形态 | 表面 | 真相 |
|---|---|---|---|
| 1 | 假绿 | 判据绿 | 扫错范围（按词法扫，该按语义扫） |
| 2 | 假红 | 判据红 | 量不到冒充差异（底层把异常折成一个合法读数） |
| 3 | 假独立 | 两个字段 | 同一个生产者写的 |
| 4 | 假互证 | 两个数 | 一个是另一个加了过滤器 |
| 5 | 假前提 | 分类有依据 | 依据与症状同源 |
| 6 | 假冗余 | 两个写入点 | 一个是另一个的派生 |
| 7 | 假见证 | 有判据在跑 | 它能证伪的集合是空集（上游已有人管） |
| 8 | 假实现 | 函数存在 | 不可达（在 return 之后 / 零调用点） |
| 9 | 冒充 | 有读数 | 名字说的与数的不一样（字段名叫 A，数的是 B） |
| 10 | 自指兜底 | 有失败记录 | 记录写回失败的那个通道本身 |

**一句总括：它们都是同一个原因——读数与它所指的对象之间那条链，有一环在我们看不见的地方。**

## 四、我们摸索出来的几条（可能不系统，可能已有更好的说法）
- 一条判据的价值 ≈ 它能证伪的东西的数量。**零 ⇒ 它不是判据。**
- 「没看到证据」≠「证据成立」。**空集读数必须配三层分母**：扫了几个文件 / 里面有几个对象 / 其中几个可能违规。
- 「量不到」≠「差异」。表示"我不知道"的值必须在**类型上**与所有合法读数可分（`None` 可分，`1` 不可分）。
- 一条判据的 **0 命中必须声明它覆盖哪些形态、不覆盖哪些**，否则 0 被读成「全面干净」。
- 新判据的第一次读数应该是**红**；若第一次就绿，先怀疑扫错了范围。
- **① 已知正确对象上不误报，必须早于 ② 人为构造的错误对象上能红。** 误报致死，漏报致病。
- 判据不能靠「抛异常」表达——`try` 里抛出的东西，接收方是 `except`，不是检查者。**同一个陷阱从 `assert` 移到 `TypeError` 仍成立。**
- 检验「一个检查器有没有坏」，必须让它过同一套检查。**否则它就是回声的最后一个藏身处。**

## 五、想请教三个问题
1. **有没有一套系统方法，判断「一条判据现在还有没有判别力」？** 我们只有上面十条，是踩出来的，而且每条都是在它已经骗过我们一次之后才写出来的。
2. **当判据与被测对象共用同一个底层函数时，怎么构造独立读数？** 具体：`cells_of(seq)` 既被 `reset` 的主保证（reset 后 cells==0）使用，又被我们新加的见证使用——两者读的是同一个函数，出错时一起被骗。
3. **验收链的最后一环是人（复核者），而终点没有见证。** 有没有办法让终点也有见证，而不是只能「可被追责」？

## 六、这些东西在别的领域叫什么（给要回答的人一个抓手）
- **mutation testing**：故意改坏被测对象，看测试红不红——我们对每条判据各做了一次，这就是上面第 7 条。
- **阴性对照 / negative control**：任何测量都必须配一个已知为阴的样本。
- **differential testing**。
- 而最接近的可能不是软件工程，是计量学：**测量不确定度**与**溯源性（traceability）**。
  我们的问题本质上就是：**这个读数能不能溯源到一个与被测对象无关的基准？** 现在不能——它只能溯源到我们自己写下的那个字面量。

**所以我们缺的那个词，很可能是「溯源性」。**
