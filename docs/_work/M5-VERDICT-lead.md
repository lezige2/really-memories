## 2 探针 (a)：换措辞（20 对）

**预登记口径（§6，分母 8/8，20 行全报）**：漏判率 **0/8**；误判率 **1/8**（`B5`「…我记得是这样。」→ 抽到 `P:这样` → unsupported，§5.3 本该放行）。
**§5.2 字面口径（作废不进分母）**：0/5、0/4 —— **事后展示口径，不是预登记承诺**（R1 在数据可见后写入，时间线 17:5x 预检 → 18:12:33 R1 → 18:13:11 跑），只能当"另眼看一遍"，不能当独立证据。
**C 组**：**3/4**（`C2`「我的车停在 3 号楼」应 undecidable，实得 supported）。**四对照组** A1/A4/B1/B6 复现上游 **4/4**。
**7 对 void 的族差异**（exhibit，不进率）：`A6 N:{602}≠{603}`、`A7 N:{602}≠{602,603}`、`A8 A:{苏A12345}≠{是B3F19K}`、`B2 P:{广陵路}≠{广陵路,我的住处}`、`B5 P:{}≠{这样}`、`B7/B8 P:{美式}≠{}`。——**注意**：§5.2 字面比的是「四族 key 逐族相等」，它实际度量的是**抽取器对改写是否稳定**，不是「样本是否改了事实」；A6/A7/A8 是构造性改事实（真该 void），B2/B5/B7/B8 是抽取器自身不稳（样本事实没改）⇒ 7 对 void 只影响 strict 分母，**不代表样本不合格**。

**实质发现（不是"探针作废"）**：① `B5` 真误判——P 族把普通短语当专名；② `B2` 靠 §9 R2 模糊命中（「我的」⊂源文）**偶然放行**；③ `B7/B8` 是**空转通过**（`facts=[]`，"supported"不是"正确放行"的证据）；④ `C2` 机制：`source_profile` 把源文日期里的 3 并入 `prof["nums"]` ⇒ `N:3` **命中** ⇒ §5.4 多重身份分支只作用于未命中项 ⇒ **该路径不可达**。

## 3 探针 (c)：长生成（4 题 × `n_predict=256`）

**计数**：总句 **69** = sup **11** + unsup **13** + undec **0** + no_fact **45**；末句未终止 **3**（单列、不进分母）；空段 47；重复句 20（照判不去重）。
**编造率 = 13/24**（unsupported / 可判句）· **存疑率 = 0/69**（undecidable / 总句数）。
**逐题**：addr 计入 14（7/2/0/5）· project 20（4/1/0/15）· habit 14（0/2/0/12）· plate 21（0/8/0/13）。
**形态**："部分正确 + 部分编造"在 **2/4** 出现（addr、project；habit/plate 不出现）。**边界 1** 样本 ⇒ supported ✓（与预期一致）。**不变量** `[]`、`round_void=false`、`frozen_sha_stable=true`。

**三条必带标注**：
1. **3/4 生成被 256 cap 截断**（addr/project/habit 接近 cap；plate 208 自然 EOS）⇒ "长生成"实为 **cap 限长**，tail 规则已正确处置，但不许宣称"自然长文"。
2. **13/24 = 判定器口径**，不是纯编造率：分子含 **2 条假阳**（addr 17「一个习惯性错」、addr 22「那些涉及地址/否有其他地方」，均为元叙述、无硬事实）+ **5 条裸「十」漏判不在分子**（addr 10/13/15/16/21，如「2 **十**单元」）。双向偏差 ⇒ 只报"判定器口径的读数"。
3. **`expected_miss=[]` 不代表没有已知漏判**：`E1`（project idx18 混合句，「项目地址是广陵路…」）应按 §5.8「归属错误」记 expected_miss，机械规则（"只出现在块外"）漏标 ⇒ **G-b**；按新规则实测候选 2 条（project 18、addr 16）。
