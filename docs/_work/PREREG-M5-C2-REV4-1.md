## 1 只改第 2 层，新增四条规则（逐字冻结）

对每个 `item{entry, evidence}`，依次应用；任一命中即 `absent=true`：

### R1 值校验
- 从 `entry` 提取值 token：数字+单位（`\d+(\.\d+)?\s*(元|度|M|G|层|楼|排|号|节|个月|年|月|日)`）、
  日期（`下?(周|星期)[一二三四五六日天]`、`\d+月\d+日`）、型号（`[A-Z]{2,}-\d{3,}`）、机构名（`[^\s，。]{2,}(公司|店|院|馆|中心)`）
- 要求该 token 出现在 `evidence` 中：**精确** 或 **字符二元组覆盖率 ≥0.80**（记 `match_mode="fuzzy"`）
- 未出现 ⇒ `absent=true`，`reason="value_mismatch"`

### R2 否定校验（**本次核心修复**）
- 归一化 `entry` 与 `evidence` 后，若存在 `entry` 的匹配位置 `i`，使得：
  - `evidence[i-6:i]` 中含否定词（`不|没|非|无|并非|不是|而不是|另一|改为|换成|不符`），**或**
  - `evidence` 匹配 `(不是|并非|而不是)\s*{entry_regex}` 或 `{entry_regex}\s*(不是|是错的)`
- 则 `absent=true`，`reason="negated"`
- **保护**：若 `evidence` 同时含 `但不是` / `并非` 而 `entry` 只作为被否定对象出现，仍判 `absent`（不得因"值出现在依据里"而放行）

### R3 缺席词表（沿用 rev4）
归一化后命中：`未提及|没有提到|未找到|找不到|未记录|无对应|无相关|未涉及|未写明|未说明|未给出|未提供|N/A|NA|None|null|—`
⇒ `absent=true`，`reason="absent_marker"`

### R4 引文校验（沿用 rev4）
`evidence` 中长度 ≥4 的引文片段（优先取引号内 / 冒号后）在 `source` 逐字不存在 ⇒ `absent=true`，`reason="fabricated_evidence"`

**整句裁决**（与 rev4 相同）：`items` 空 ⇒ `undecidable`；任一 `absent` ⇒ `unsupported`；全部否则 ≥1 ⇒ `supported`；
无法归类 ⇒ `unverified` ⇒ `undecidable`。
**推理型旁路**：句子含 `共|总共|合计|一共|平均|最|加起来` ⇒ 强制 `undecidable`（禁判 `unsupported`）。
