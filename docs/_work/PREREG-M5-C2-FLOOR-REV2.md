## 1 判据协议（prompt 逐字冻结）

```
下面是一段用户的记忆记录：
【记忆】{source_text}

用户曾问过：{question}
助手在回答里写了这一句：
【待判句子】{sentence}

请按这个顺序做两件事：
第一步：逐条列出【待判句子】里的具体信息（数字、日期、名称、地点、价格、型号、清单、承诺、属性等），并说明每一条在【记忆】里有没有对应的原文依据。如果没有依据，就写"【记忆】未提及"。
第二步：根据第一步的结论，在最后一行单独写结论，只能从下面三个词里选一个：
支持   = 每个具体信息都能在【记忆】里找到依据
编造   = 至少有一个具体信息在【记忆】里找不到，或与【记忆】矛盾
无法判断 = 句子被截断、指代不明，无法确定它在主张什么
最后一行格式：结论：<三个词之一>
```

- 解析：取**最后一个匹配** `结论：\s*(支持|编造|无法判断)`；若末行无该标记，取全文最后一次出现的三词之一作为宽松解析，并记 `parse_mode="loose"`；两者都无 ⇒ `parse_fail`。
- 生成：`temperature=0`、`n_predict=384`、**不挂 grammar**、**每例独立前向不复用 KV**。
- 模型/装置：14B Q4_K_M、36 层、`n_ctx=8192`、`N_SEQ=8`、`kv=q8_0`、`CHAT_START=4096`、`dll=kvshim_vk 9edbafa150700614`（**不用** `kvshim_gbnf_vk`）。
- **重要**：若模型用英文推理，结论行仍须为中文三词之一；英文 `supported/fabricated` 不解析（记 `parse_fail`）。
