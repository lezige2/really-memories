- 1 次 save→新进程 load 探针：`pos_saved == pos_after_load`、`n_tokens` 一致、`load_return` 一致。
- 安全：VRAM 目标 ≤8.0 GiB、8.6 GiB 熔断、单场景 ≤900 s、父进程不发信号（子轮询 stop flag 100–200 ms）、host gate（boot id / free RAM ≥8,388,608 kB / 基线 VRAM ≤1.5 GiB（K1 修订口径）/ 无 >256 MiB GPU 进程 / dump 计数不变）。

- **未接上**：装置/门/熔断/样本量不足/标注不可靠。
